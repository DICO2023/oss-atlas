# Tarea 1 — Documentación del Proyecto (Markdown)

El documento canónico de la Tarea 1 es el `README.md` de la raíz del repo
(manifiesto arquitectónico completo: problema, equipo, RACI, arquitectura,
modelo de datos, búsqueda híbrida, ingesta, RAG, frontend, API, RAGAS,
cronograma, riesgos y trazabilidad de entregables).

No se duplica el contenido aquí para evitar que las dos copias diverjan:
toda corrección se hace en el `README.md` raíz y, si cambia una decisión,
se registra una ADR en `docs/arquitectura/adr/`.
