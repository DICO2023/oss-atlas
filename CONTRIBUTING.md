# Contribuir

1. Crea una rama desde `main`: `feat/<tema>`, `fix/<tema>` o `docs/<tema>`.
2. Sigue el protocolo de traspaso asíncrono (ver README): evidencia, cambios,
   bloqueos, próxima acción (verbo, responsable, fecha), decisiones retenidas.
3. Abre un PR con la plantilla de `.github/PULL_REQUEST_TEMPLATE.md`.
4. Code Freeze: 9 nov 2026. Desde entonces solo cambios en `docs/` y `video-demo/`.
