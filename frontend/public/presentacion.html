⚡ Event-Driven B2B Pipeline

Conectividad & Triggers: Comunicación entre Capas

El mapa RAG B2B no es un diagrama estático; define los disparadores técnicos (triggers) que orquestan el flujo de datos seguro entre cada nivel.

DISPARADOR CAPA 1 → CAPA 2
Token RS256 & Context Injection
El cliente se autentica en Keycloak vía OIDC. El API Gateway valida la firma criptográfica RS256 e inyecta el Tenant ID y permisos RBAC en la sesión PostgreSQL con Row-Level Security (RLS).
Evento: `OIDC JWT Bearer Issuance`
DISPARADOR CAPA 2 → CAPA 4
HNSW Vector Search on Change
Al insertar o modificar contratos o pedidos en PostgreSQL, un disparador (`ON INSERT row`) invoca el pipeline de embeddings que actualiza el índice `halfvec(1536)` en memoria para inferencia RAG.
Evento: `RRF Hybrid Query RPC`
DISPARADOR CAPA 4 → CAPA 3
Verified Agent Payment Intent
El asistente RAG analiza la cotización y, solo tras certificar fidelidad RAGAS = 1.00, despacha una llamada idempotente al endpoint de Hyperswitch para enrutar el cobro interbancario.
Evento: `Checkout Session Webhook`
Pipeline: Client (HTTPS) → Keycloak JWT → FastAPI Gateway → Postgres RLS → pgvector HNSW → LangChain RAG → Hyperswitch RPC
Cero Acoplamiento: Microservicios comunicados por APIs REST y Webhooks JSON estándar.

⚙️ Anatomía del Backend

Cómo Funciona el Endpoint /api/v1/rag/architecture

El flujo interno que transforma un texto de requerimiento en una arquitectura completa y validada matemáticamente.

1
Vectorización & FTS
El endpoint normaliza el texto, elimina stopwords y genera un vector de 1536 dimensiones. Simultáneamente, construye la consulta léxica `to_tsquery('simple', ...)`.
halfvec(1536) Lexical tokens
2
Fusión Recíproca (RRF k=60)
PostgreSQL ejecuta ambas ramas en paralelo. RRF fusiona los rankings eliminando sesgos de palabras clave o variaciones de embeddings:
1/(60+r_lex) + 1/(60+r_vec)
HNSW <=> Distance ts_rank_cd
3
Estructuración Multicapa
El asistente asigna cada herramienta ganadora a su capa correspondiente (Auth, DBS, Payments, AI), redacta el resumen ejecutivo e invoca el dimensionamiento de hardware.
4 Capas Mapeadas Justificación ACID
