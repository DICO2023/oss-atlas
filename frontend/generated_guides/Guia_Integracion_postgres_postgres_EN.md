## 3. Step-by-Step for Windows (PowerShell & WSL2)

### 3.1. Verify WSL2 & Docker Desktop
```powershell
# Comprobar estado de WSL2
wsl --status
wsl --update

# Verificar daemon de Docker
docker version
```

### 3.2. Volume Persistence & Session Variables
```powershell
# Crear directorio de datos persistente
$env:DATA_PATH = "$HOME\oss-atlas-data\postgres_postgres"
New-Item -ItemType Directory -Force -Path $env:DATA_PATH

# Configurar puerto y ambiente
$env:PORT = "5432"
$env:NODE_ENV = "production"
```

### 3.3. Deploy Container
```powershell
docker run -d --name postgres-core -p 5432:5432 -e POSTGRES_PASSWORD=postgres postgres:16-alpine --restart unless-stopped
```

### 3.4. Endpoint Healthcheck
```powershell
# Verificar logs iniciales
docker logs --tail 30 (docker ps -lq)

# Probar endpoint HTTP
Invoke-RestMethod -Uri "http://localhost:5432" -Method GET -ErrorAction SilentlyContinue
```

## 5. Production Security Hardening Checklist

1. **Network Isolation:** Create dedicated bridge networks (`docker network create oss-net`) to avoid uncontrolled host port exposure.
2. **Secrets Management:** Inject passwords through `.env` files protected with `chmod 600` permissions.
3. **Automated Backups:** Schedule daily automated volume snapshots to encrypted cloud storage.
4. **CVE Audit:** Monitor security advisories subscribed from the active OSS Atlas catalog.
