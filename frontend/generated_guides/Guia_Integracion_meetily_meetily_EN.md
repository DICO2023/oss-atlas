## 2. Technical Description & Prerequisites

- `Whisper.cpp / ffmpeg`
- `CUDA opcional`

## 3. Step-by-Step for Windows (PowerShell & WSL2)

### 3.1. Verify WSL2 & Docker Desktop
```powershell

wsl --status
wsl --update

# Verificar daemon de Docker
docker version
```

### 3.2. Volume Persistence & Session Variables
```powershell
# Crear directorio de datos persistente
$env:DATA_PATH = "$HOME\oss-atlas-data\meetily_meetily"
New-Item -ItemType Directory -Force -Path $env:DATA_PATH

# Configurar puerto y ambiente
$env:PORT = "3010"

```

### 3.3. Deploy Container
